Event Registration Formatter:

Description:
A Python program that collects student registration details, cleans messy text inputs using string methods, and formats the event date into a clear, readable summary.

Features Used:
- Language: Python
- String Methods: `strip()`, `title()`, `upper()`
- Date/Time Library: `datetime` (`datetime.date`, `strftime()`)

Version History:
- Version 1: Basic input and output without formatting.
- Version 2: added string cleaning and capitalization methods.
- Version 3: Added readable date formatting using `datetime`.
